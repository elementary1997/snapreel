## Что заслуживает ADR

Решение, которое влияет на структуру или зависимости, трудно обратимо либо
выглядит без объяснения странно. Мелкие правки и очевидные выборы — не сюда.

## Открытые вопросы

Кандидаты в будущие ADR, решение по которым ещё не принято:

- Поддержка Wayland в GNOME и KDE через xdg-desktop-portal и PipeWire.
- Формат для чатов LLM-агентов: остаётся ли GIF единственным способом
  «показать» запись модели.
- Упаковка в один исполняемый файл (PyInstaller) против установки из исходников.
