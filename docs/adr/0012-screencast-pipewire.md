# 12. ScreenCast/PipeWire и файловый буфер Wayland

Дата: 2026-10-03

## Status

Accepted. Уточняет ADR-0003 и ADR-0010 для KDE/GNOME Wayland.
Решение об отсутствии рамки в KDE уточнено ADR-0013.

## Context

wf-recorder работает с wlroots, но не с KWin и Mutter. Портал ScreenCast
предоставляет разрешённые пользователем потоки PipeWire. Вшитый минимальный
ffmpeg не умеет читать этот транспорт. Qt Wayland не гарантирует произвольное
расположение окон: рамка и панель могут попасть в записываемую область.
Один MIME-тип wl-copy ограничивал совместимость вставки файлов в Qt и Electron.

## Decision

Добавляем отдельный CaptureBackend для KDE/GNOME Wayland, сохраняя wf-recorder
для wlroots. Портал запрашивает мониторы и курсор, получает PipeWire remote;
повторные потребители получают новые сокеты. Выделение идёт на снимке разрешённых
экранов. Позиции и размеры берём из метаданных портала; при отсутствии размера
измеряем кадр, при отсутствии позиции размещаем потоки рядом. Поэтому координаты
явной области относятся к снимку, а не обязательно к глобальным координатам Qt.

Записывает системный GStreamer через стабильный C API ctypes, без gi или новых
Python-зависимостей. Служебный процесс того же бинарника изолирует плагины от Qt:
окна, портал и оркестрация остаются в трее. Он обрезает и компонует потоки,
кодирует H.264/AAC и завершает MP4 через EOS. На EOS videorate не дополняет
закрывающий сегмент дубликатами: это могло превысить ограничение длительности.
GIF собирается существующим ffmpeg. Зависимости GStreamer предлагает setup,
только с подтверждением пользователя. Системные библиотеки GStreamer/GLib/
Wayland не кладём в PyInstaller, чтобы плагины не загружались с чужим ABI.

Остановить запись можно из меню трея либо повторной комбинацией после
минимального времени. Разовая команда создаёт временную иконку. Рамку и
плавающую панель не показываем: на Wayland нельзя надёжно вывести их за кадр.

Для регистрации порталов используем отдельное D-Bus-соединение и Registry
с идентификатором org.snapreel.Snapreel. Его скрытый desktop-файл не включает
автозапуск, не перезаписывает чужой файл и удаляется при uninstall. Restore
токен хранится локально с режимом 0600; записанные кадры не кешируются.

В KDE/wlroots буфер держит отдельный процесс libwayland-client data-control:
только text/uri-list и x-special/gnome-copied-files. Он не читает прежний буфер
и завершается при смене владельца. Без протокола сохраняем fallback wl-copy.

## Consequences

- Нативная приёмка выполнена на Debian 13.7, Plasma/KWin 6.3.6, Wayland:
  оба события GlobalShortcuts, снимок и выбор области, H.264/AAC MP4, GIF,
  ограничение 5 секунд и получение файла обычным Qt-клиентом.
- GNOME использует тот же ScreenCast-контракт, но не прошёл эту нативную приёмку;
  наличие GlobalShortcuts и data-control зависит от версии окружения.
- CLI doctor остаётся без окон и запросов разрешений.
- X11, Windows, macOS и запрет записи экрана Windows из WSL не меняются.
