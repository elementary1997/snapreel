# ADR-0004: Основной способ вызова — системный хоткей, демон вторичен

## Status

Accepted (2026-09-05)

## Context

Инструмент бесполезен без горячей клавиши. Очевидное решение — фоновый
процесс, который перехватывает клавиатуру через `pynput`. Но:

- В Wayland композитор принципиально не отдаёт глобальные клавиши приложениям.
  Демон там не заработает никогда, это не баг библиотеки.
- В macOS перехват требует разрешения «Универсальный доступ» и выглядит для
  пользователя как кейлоггер.
- Демон надо держать запущенным, добавлять в автозапуск и следить, что он жив.
- Пользователь хочет выбирать комбинацию сам, а разные ОС по-разному
  резервируют сочетания.

## Decision

Основной механизм — **горячая клавиша, зарегистрированная средствами самой
ОС**, вызывающая одноразовую команду `snapreel record`:

- GNOME — своя комбинация в `media-keys` через `gsettings`, ставится автоматически.
- Windows — ярлык в меню «Пуск» со свойством `Hotkey`, ставится автоматически.
- Остальные окружения (KDE, i3, Sway, macOS) — snapreel печатает готовую
  команду, пользователь привязывает её штатными средствами.

Комбинацию всегда задаёт пользователь: `snapreel setup` спрашивает её,
`snapreel hotkey set 'Ctrl+Alt+5'` меняет. Ввод принимается в свободной форме
(`Ctrl+Alt+5`, `Win+Shift+S`, `<ctrl>+<alt>+r`) и нормализуется в один вид.

Демон (`snapreel daemon` на `pynput`) остаётся как дополнительная возможность —
для второй комбинации (GIF) и для тех, кому так удобнее.

## Consequences

+ Работает в Wayland, где демон невозможен в принципе.
+ Ничего не висит в памяти между записями; хоткей переживает перезагрузку.
+ `pynput` остаётся необязательной экстрой `.[daemon]`.
- Автоматическая регистрация покрывает только GNOME и Windows; в остальных
  окружениях остаётся ручной шаг.
- Каждый вызов — новый процесс Python, то есть задержка старта интерпретатора
  (десятки миллисекунд) перед появлением оверлея.
- Вторая комбинация (GIF) системно не назначается — только через демон или
  второй ярлык, созданный вручную.

## Alternatives considered

- **Только демон на pynput** — отвергнуто: не работает в Wayland, требует
  разрешений в macOS, нуждается в автозапуске.
- **Комбинация зашита в код** — отвергнуто прямым требованием: пользователь
  выбирает клавиши сам на любой системе.
- **Своя служба с перехватом на уровне драйвера** — несоразмерно и выглядит
  враждебно для антивирусов.
