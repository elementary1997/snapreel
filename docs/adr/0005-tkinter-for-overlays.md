# ADR-0005: Оверлеи выделения и записи — на tkinter

## Status

Accepted (2026-09-05)

## Context

Нужны два экранных элемента: полноэкранный затемнённый слой для выделения
прямоугольника мышью и рамка с таймером во время записи. Требования —
все три ОС, поверх всех окон, произвольная геометрия (включая мониторы с
отрицательными координатами) и никаких новых зависимостей (см. ADR-0003).

## Decision

Обе поверхности — на `tkinter` из стандартной библиотеки.

Оверлей выделения — одно окно `overrideredirect` на весь виртуальный рабочий
стол с `-alpha 0.35`; координаты берутся из `event.x_root`/`y_root`, то есть
сразу в системе виртуального стола — той же, в которой их ждут gdigrab и
x11grab. На macOS вместо `overrideredirect` используется `-fullscreen`:
у Aqua первое надёжно не работает.

Индикатор записи — **четыре тонких окна по краям области** плюс отдельная
панель с таймером. Одно окно поверх области не годится: оно попало бы в кадр.

Импорт `tkinter` ленивый: он есть не во всякой сборке Python, а `snapreel
doctor` обязан работать именно тогда, когда его нет.

## Consequences

+ Ни одной внешней зависимости для GUI.
+ Один код на три платформы, с двумя точечными развилками.
+ Без tkinter приложение остаётся частично работоспособным: `doctor`,
  `config`, `prune` и запись с явным `--region`.
- Внешний вид скромный: Tk не даёт скруглений, теней и попиксельной
  прозрачности.
- Настоящей «дырки» в затемнении сделать нельзя — прозрачность задаётся окну
  целиком, поэтому выделенная область показывается рамкой поверх общего
  затемнения.
- Полоски рамки перехватывают клики по самому краю области.
- В Debian/Ubuntu tkinter — отдельный пакет `python3-tk`; это учтено в `deps.py`.

## Alternatives considered

- **PyQt / PySide** — качественный оверлей и настоящая прозрачность, но
  ~50 МБ зависимостей и лицензионные вопросы у Qt. Несоразмерно двум окнам.
- **GTK через PyGObject** — родной для Linux, но на Windows и macOS ставится
  тяжело и плохо.
- **Готовые утилиты выделения (`slurp`, `slop`)** — только Linux, и каждая
  тянет свой стек.
- **Веб-оверлей на pywebview** — тяжелее tkinter и хуже держит «поверх всех окон».
